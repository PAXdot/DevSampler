# ANDA

Local gallery: components, templates, themes, apps, icons and video.

```bash
npm run dev
```

Open http://localhost:3000. The gallery reads the files already on disk.

`data/catalog.jsonl` is the catalog. Component source is in `data/sources`, theme CSS in `data/themes`, and video blocks in `data/video.json`. Preview images and loops live in `public/media` on the machine that downloaded them; that folder is about 2.5 GB and is not in git.
